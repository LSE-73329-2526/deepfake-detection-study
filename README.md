# Deepfake Detection, Media Literacy, and Media Dependency (Scope & Centrality)

Analysis code for dissertation examining associations between media literacy, 
media dependency, and deepfake detection ability among Gen Z university 
students in Metro Manila, Philippines.

## Files
- `Survey_Instrument.pdf` — survey deployed in the study, pdf file
- `Survey_Instrument.qsf` — survey deployed in the study, qsf file
- `analysis_code.ipynb` — code for all analysis, tables, and figures 

## Note
Raw survey data is not included due to respondent anonymity commitments 
made under LSE ethics approval.
